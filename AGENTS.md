# Project: transactions-tracker

A blank **TanStack Start** application (React). This is the initial scaffold — no
business/domain features have been built yet.

## How this project was scaffolded

Generated with the TanStack CLI, then merged into this pre-existing git repo:

```bash
# Run in a scratch directory (repo root already existed with .git)
npx @tanstack/cli@latest create my-tanstack-app --agent --package-manager pnpm --tailwind
```

Notes on that command:

- `--tailwind` is now **deprecated and ignored** by the CLI — Tailwind is always
  enabled in TanStack Start scaffolds. Tailwind v4 is present regardless.
- `--agent` produces the non-interactive, agent-friendly output (AGENTS.md wired
  up with TanStack Intent skill mappings).
- The CLI created a `my-tanstack-app/` subfolder; its contents (minus its own
  `.git` and `node_modules`) were merged into this repo root, then
  `pnpm install` was run here.

Follow-up TanStack Intent commands (run from repo root):

```bash
npx @tanstack/intent@latest install   # writes/refreshes the Skill Loading block above
npx @tanstack/intent@latest list      # lists locally available skills
```

## Stack & integrations

- **Framework:** TanStack Start (React 19) — full-stack SSR, file-based routing.
- **Router:** TanStack Router (file router, `src/routes/`, generated `routeTree.gen.ts`).
- **Build/dev:** Vite 8 with `@tanstack/react-start/plugin/vite`, `@vitejs/plugin-react`.
- **Styling:** Tailwind CSS v4 via `@tailwindcss/vite` (+ `@tailwindcss/typography`).
- **Devtools:** TanStack Devtools + Router Devtools, wired via `@tanstack/devtools-vite`
  (stripped from production builds automatically).
- **Testing:** Vitest 4 + Testing Library + jsdom.
- **Language:** TypeScript 6. Path alias `#/*` → `./src/*` (see `package.json` `imports`).
- **Agent guidance:** TanStack Intent (skill mappings; see Skill Loading block above).
- No extra partner integrations, auth, or DB add-ons were selected (blank starter, as requested).

## Scripts

```bash
pnpm dev              # vite dev on http://localhost:3000
pnpm build            # production build (client + SSR) into dist/
pnpm preview          # preview the production build
pnpm test             # vitest run
pnpm generate-routes  # tsr generate (regenerate routeTree.gen.ts)
```

## Project structure

- `src/router.tsx` — `getRouter()` factory + router type registration.
- `src/routes/__root.tsx` — root shell (`shellComponent`, `HeadContent`, `Scripts`, theme init).
- `src/routes/index.tsx`, `src/routes/about.tsx` — example pages.
- `src/components/` — `Header`, `Footer`, `ThemeToggle` (starter UI).
- `src/routeTree.gen.ts` — **generated**, do not edit by hand (regenerated by `tsr generate`).
- `src/styles.css` — Tailwind entry.
- `tsr.config.json` — router generator config (`target: react`).
- `.tanstack/` — Intent working dir (gitignored).

## Environment variables

None are required to run the blank starter today. When you add them:

- Only variables prefixed `VITE_` are exposed to client bundles. Everything else
  stays server-only (accessed in server functions / middleware).
- Use a local `.env` (already gitignored). Do not commit secrets.

## Deployment

No deploy target configured yet. TanStack Start builds to a server bundle
(`dist/server/server.js`) plus client assets. To target a specific platform
(Cloudflare Workers, Netlify, Vercel, Node/Docker, Bun), load the deployment
skill first: `pnpm dlx @tanstack/intent@latest load @tanstack/start-client-core#start-core/deployment`.

## Key decisions / gotchas

- Scaffolded in a scratch dir and merged because the repo already had `.git`;
  the scaffold's `.gitignore` (fuller) replaced the original one-line one.
- `routeTree.gen.ts` is generated — it's marked read-only in `.vscode/settings.json`.
- Devtools code is auto-removed from production builds by `@tanstack/devtools-vite`.
- pnpm warns that the `pnpm.onlyBuiltDependencies` field placement is legacy; harmless.
